# Small format fixture

`basic.glyf` describes one synthetic image, two annotations (Point and Region)
and one clipped part. `basic.glyp` contains the matching `sample.png` resource.
The image is a generated geometric checkerboard; all three files are project
fixtures under the root MIT License.

This is not a captured UI report and was not created through an Editor
automation scenario. It exercises the public parser/container/CLI example.
